Application Windows · Local-first

Structurez vos appels d’offres. Simplifiez leur suivi.

Créateur d’AO normalise les dossiers, automatise leur arborescence, facilite les transferts et synchronise le suivi entre plusieurs postes sans imposer de serveur applicatif.

Workflow

Un même outil du premier dossier au résultat final.

Les opérations répétitives restent dans le logiciel, tandis que les fichiers continuent à vivre dans les emplacements choisis par l’organisation.

01

Création normalisée

Convention de nommage cohérente, arborescence configurable et génération physique des dossiers en quelques secondes.

02

Transfert maîtrisé

Sélection native Windows, relecture des informations, renommage et déplacement vers les destinations configurées.

03

Suivi partagé

À attribuer, En cours, Envoyé, Gagné ou Perdu : l’état des dossiers est lisible sans parcourir manuellement le serveur.

04

Historique et données utiles

Contacts, prix, remarques, relances et journal des actions restent disponibles depuis une vue centralisée.

Architecture

Rapide localement, collaboratif sur le réseau.

Chaque poste conserve sa propre base SQLite. Le partage réseau transporte uniquement des événements légers, pas une base ouverte simultanément par tout le monde.

Poste A · Electron + SQLite local
↕
Dossier partagé · Journal d’événements
↕
Poste B · Electron + SQLite local

Local-first par conception.

Cette approche permet de conserver une interface fluide, de limiter les accès réseau et de s’intégrer à une infrastructure de fichiers Windows existante.

Pas de serveur applicatif obligatoire Pas de dépendance cloud pour le fonctionnement normal Base utilisateur locale Synchronisation multi-postes via un simple partage Déploiement possible sans droits administrateur
Déploiement

Installer une fois, ou distribuer depuis un serveur.

L’application peut être installée classiquement ou copiée automatiquement depuis une référence centralisée vers le profil local de chaque utilisateur.

Installation Windows

Un installateur utilisateur crée les raccourcis nécessaires sans dépendre d’une installation système globale.

Distribution centralisée

Un lanceur réseau synchronise les fichiers applicatifs vers %LOCALAPPDATA%, puis démarre la copie locale.

Confidentialité

Vos données restent dans vos emplacements.

Le dépôt ne contient aucun chemin métier requis pour faire fonctionner le produit. Destinations, arborescences et partages sont choisis lors de la configuration.
